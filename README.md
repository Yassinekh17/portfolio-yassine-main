# 🚀 Personal Portfolio

A modern developer portfolio built with **Next.js** to showcase my projects, skills, and experience.

## 🛠 Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## 📦 Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```
http://localhost:3000
```

in your browser.

## 📂 Features

- Responsive design
- Smooth animations
- Project showcase
- Skills section
- Experience timeline
- Contact section
- Optimized performance
